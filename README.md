## 🚀 Featured Project

### ♻️ AI-Based Smart Waste Segregation Assistant

**Role:** Machine Learning & Full Stack Developer

A CNN-based AI system designed to classify waste images into multiple categories and integrated with a Flask-based web application for real-time prediction.

#### Problem
Manual waste segregation can reduce recycling efficiency and contribute to environmental pollution.

#### Solution
Built a CNN-based model and integrated it with a Flask API to provide automated waste classification through a web interface.

#### Tech Stack

| Layer | Technologies |
|---|---|
| AI / Computer Vision | PyTorch, OpenCV, NumPy, Scikit-learn |
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| Database | N/A |

#### Key Features

- ♻️ Real-time waste classification
- 🤖 AI-powered prediction
- 🌐 Web-based interface
- 🧠 CNN-based image classification

#### Challenge

Improving model accuracy when working with diverse waste images.

#### Outcome

Successfully developed an AI-powered waste classification system.
