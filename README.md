## 🚀 Completed Project

### ♻️ AI-Based Smart Waste Segregation Assistant

**Status: ✅ Completed**

**Role:** Machine Learning & Full Stack Developer

Developed a **CNN-based AI system** to classify waste images into multiple categories and integrated it with a **Flask-based web application** for real-time prediction.

#### 🎯 Problem
Manual waste segregation can reduce recycling efficiency and contribute to environmental pollution.

#### 💡 Solution
Built a CNN model and integrated it with a Flask API to provide automated waste classification through a web interface.

#### ⚙️ Tech Stack

| Area | Technologies |
|---|---|
| AI / Computer Vision | PyTorch, OpenCV, NumPy, Scikit-learn |
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| Prediction | CNN-based image classification |

#### ✨ Key Features

- ♻️ Real-time waste classification
- 🤖 AI-powered prediction
- 🌐 Web-based interface
- 🧠 CNN image classification
- 📈 Model evaluation and improvement
