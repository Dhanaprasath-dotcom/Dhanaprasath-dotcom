## 🚀 Featured Project

### ♻️ AI-Based Smart Waste Segregation Assistant

**Role:** Machine Learning & Full-Stack Developer

An AI-powered computer vision system designed to automatically classify waste images into multiple categories and assist with waste segregation.

#### Problem

Manual waste segregation can reduce recycling efficiency and contribute to environmental pollution.

#### Solution

Developed a **CNN-based image classification system** and integrated the trained model with a **Flask web application** for real-time prediction.

#### ML Workflow

```text
Waste Images
     ↓
Data Preprocessing
     ↓
CNN Model
     ↓
Model Training
     ↓
Model Evaluation
     ↓
Flask Integration
     ↓
Web Application
     ↓
Real-Time Prediction
```

#### Technologies

**Machine Learning:** PyTorch, Scikit-learn  
**Computer Vision:** OpenCV  
**Data Processing:** NumPy  
**Backend:** Python, Flask  
**Frontend:** HTML, CSS, JavaScript

#### Key Features

- ♻️ Waste image classification
- 🧠 CNN-based AI prediction
- 🖼️ Image preprocessing
- ⚡ Real-time prediction
- 🌐 Web-based interface
- 🔗 ML model and Flask integration

#### Challenge

Improving model accuracy and robustness when working with diverse waste images.
